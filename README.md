# TOOLFAB TOWERS website

Single-file PHP corporate site for TOOLFAB Towers.

- `index.php` — main site (all pages via `?p=slug`)
- `index2.php` — alternative home-page layout (preview)
- `assets/` — images, logos, certification badges and hero video

Run locally with any PHP server (e.g. Laravel Herd) and open `index.php`.
